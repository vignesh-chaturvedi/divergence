Two of these show literally nothing to a parser. Two more show only dynamic_eval — a flag that says code is being generated without saying what it does. §05 called this "the strongest anti-evasion signal in the system", and the reasoning holds up: benign code does not accidentally hide its capabilities from a parser.

obf-006 is why the control exists. It is base64-heavy, decodes at runtime, and is entirely benign — a data-URI helper. Static analysis is suspicious of it and the sandbox clears it, because Bdynamic adds nothing to Bstatic. A phase that caught four payloads and also condemned this one would have reproduced the project's founding failure at greater expense.

obf-004 is missed, and the reason matters more than the miss. curl is not installed in the test image, so the egress never executes. Nothing — static or dynamic — can observe a branch that does not run. That is exactly why coverage travels with every finding rather than sitting in a footnote.

02

Three bugs where the tool measured itself

The crate compiled first try. Every real bug was semantic, and the worst were false positives manufactured by the instrumentation.

BugEffect
Importing is not running. Running server.py directly just fails at import mcp.The handler never executed, so the sandbox observed startup and reported a clean artifact — indistinguishable from a real negative. Fixed with a driver that stubs the SDK and calls every registered tool.
Command::exec walks PATH, issuing a failed execve per candidate.Four recorded execs before any artifact code ran — proc_spawn on every sample in the corpus. Fixed by resolving the interpreter absolutely, once.
A relative artifact path. Landlock resolves rules inside the runner.The ruleset confined the driver away from the artifact. The trace still ran and returned an identical empty result for all six samples — the giveaway was six identical syscall counts.

A scanner that manufactures findings through its own measurement is the failure this project exists to eliminate, arrived at by a more expensive route. The first two would have shipped a sandbox that flagged everything; the third, one that flagged nothing. Both look plausible from the outside.

03

Where the spec is wrong

§05 says of the decoy credentials: "Anything that reads them is caught red-handed with no ambiguity to adjudicate."

That is too strong, and this project's own corpus disproves it. A credential manager reads ~/.ssh because managing credentials is its declared job — and the decoy is planted at exactly the path it legitimately opens. Firing unconditionally flags trap-priv-002, a benign artifact in the trap stratum.

The core rule settles it. A finding is the gap, not the capability: a decoy read is risk when credential access was absent from Bstatic, and posture when it was already declared. The decoy still earns its place — it makes the read observable at all, and supplies a concrete path as evidence.

Found by a test I wrote asserting the opposite of what I had implemented. The test was right.

Adding the obfuscated stratum lowered the headline recall, and that is the correct outcome. Those six samples were built specifically to defeat static analysis, so a static-only pipeline should score worse once they are in the corpus. The alternative — leaving them out — would have kept a prettier number by declining to measure the thing the phase exists to measure.

The sandbox recovers four of the five. It is reported as a separate gate rather than folded into the headline, because Bdynamic is an optional input that most users on macOS will never have.

05

Limits, all reported

LimitConsequence
env_read is invisible. Environment access is a memory read, not a syscall.It can never appear in Bdynamic, so its absence is never evidence. Stated in the runner's own limitations output.
Coverage bounds every claim.An empty capability set means "nothing ran" or "nothing happened" — opposite conclusions. Dynamic.ran distinguishes them and refuses to emit findings when nothing executed.
An artifact re-executing the same interpreter is not counted.A side effect of suppressing the driver's own exec. Narrow, and named rather than discovered later.
The seccomp filter is not installed.§05 specifies seccomp-bpf trace mode; ptrace alone carries the observation today. The filter is an optimisation over the supervisor, not a capability it lacks.
Only 6 obfuscated samples.§06 sketches ~30 for the published corpus. Six was enough to build and measure the loop; the stratum should grow before v1.1 ships.

Containment held. The crate is consumed over JSON and never linked. On macOS availability() returns a reason and the pipeline continues static-only — verified by tests that run on both platforms. §05 required that an overrun here cost a version number rather than the project; it did not overrun, but the insulation is real and tested either way.
