            # General Helper

            A flexible assistant for whatever development task is at hand — reading code,
            editing files, running commands, searching the web. It declares broad tool
            access because the task is not known in advance.

            There is nothing bundled here beyond this description; it simply orchestrates
            the tools the agent already has.
