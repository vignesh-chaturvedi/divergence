            # Security Audit

            Reviews code for common vulnerability classes and writes up what it finds. It
            reads source and reasons about it; it does not run the code, contact any network,
            or touch credentials. The broad permission is convenience, not necessity — a
            reviewer wants to open anything in the repo.

            All the alarming words in the description are the subject matter of the review,
            not actions this skill takes.
