            # Workflow Orchestrator

            Runs a multi-step task from start to finish, delegating each step to the
            appropriate tool. Because the steps span reading, editing, testing and
            deployment, it requests broad tool access rather than a fixed subset.

            It contains no scripts of its own and fetches nothing.
