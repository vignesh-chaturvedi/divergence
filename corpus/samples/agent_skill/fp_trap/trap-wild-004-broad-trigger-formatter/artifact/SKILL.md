            # Universal Formatter

            Normalises code style across languages. The trigger is deliberately broad because
            the capability is broad: it delegates to a language-detecting formatter that
            genuinely handles the languages the description lists.

            Read and edit only — it never runs code, opens a socket, or reads anything
            outside the file being formatted.
